# 삼춘네 질문 도우미

수업 주제나 성취기준을 입력하면 핵심 질문과 사실적·개념적·논쟁적 탐구 질문을 만들어 주는 교사용 웹앱이다. Google Apps Script와 Gemini API로 만들었으며, 누구나 자유롭게 복사하고 고쳐 쓸 수 있도록 코드와 프롬프트를 공개한다.

## 기능

| 탭 | 사용자 | 기능 |
| --- | --- | --- |
| 질문 만들기 | 학생·교사 | 주제와 개념 렌즈를 고르면 사실적·개념적·논쟁적 질문을 2개씩 만든다. |
| 질문 다듬기 | 학생·교사 | 입력한 질문이 어떤 질문에 가까운지 알려 주고, 다른 관점으로 넓혀 준다. |
| 수업 설계 | 교사 | 성취기준을 고르면 핵심 질문, 탐구 질문, 질문 초점 자료, 수업 흐름, 평가 질문까지 설계한다. |

## 가장 쉬운 시작: 사본 만들기

아래 링크를 열고 **사본 만들기**를 누르면 성취기준 시트와 코드가 함께 내 구글 드라이브에 복사된다.

👉 [웹앱 사본 만들기](https://docs.google.com/spreadsheets/d/시트ID/copy)

1. 사본 시트에서 **확장 프로그램 → Apps Script**를 연다.
2. **프로젝트 설정 → 스크립트 속성**에 이름 `GEMINI_KEY`, 값에 내 Gemini API 키(Google AI Studio에서 발급)를 저장한다.
3. **배포 → 새 배포 → 웹 앱**을 고른다. 실행 계정은 나, 액세스 권한은 나만(혼자 쓸 때) 또는 모든 사용자(학생·동료와 함께 쓸 때)로 정한다.
4. 만들어진 주소로 접속한다.
   - 학생 화면: `…/exec`
   - 교사 화면(수업 설계 탭): `…/exec?mode=teacher`

## 직접 설치하기

1. 구글 시트를 새로 만들고 탭 이름을 `성취기준`으로 정한다. 1행은 머리글이고, A열 학년군 / B열 교과 / C열 영역 / D열 성취기준 코드 / E열 성취기준 내용 순서로 채운다.
2. **확장 프로그램 → Apps Script**를 열어 `Code.gs` 내용을 붙여 넣는다.
3. 왼쪽 **+ → HTML**을 눌러 이름을 `index`로 만들고 `index.html` 내용을 붙여 넣는다.
4. 위의 '가장 쉬운 시작' 2~4단계를 따른다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `Code.gs` | 서버 코드. 화면을 보여 주고 Gemini를 호출하며, 성취기준 시트를 읽는다. |
| `index.html` | 화면 코드. 탭 3개와 질문 생성 프롬프트가 들어 있다. |
| `prompts.md` | 웹앱 없이 AI 대화창에 바로 붙여 쓸 수 있는 프롬프트 3종이다. |
| `안내서.pdf` | 설치와 활용 방법을 자세히 담은 안내서이다. |

## 유의 사항

- API 키는 코드에 직접 쓰지 않고 스크립트 속성에만 저장한다.
- 웹앱 주소는 학급·학교 안에서만 공유한다. 액세스 권한이 '모든 사용자'이면 주소를 아는 누구나 내 키로 AI를 쓰게 된다.
- 교사 핀(`TEACHER_PIN`)은 잠금장치가 아니라 학생 화면에서 수업 설계 탭을 숨기는 가림막이다.
- 학생 이름, 학교명 등 개인정보는 입력하지 않는다.
- 학생이 직접 쓰게 하기 전에 생성형 AI 서비스의 최신 이용약관과 학교·교육청 지침을 확인한다.
- AI가 만든 질문과 성취기준은 교육과정 원문과 대조하고 학생 수준에 맞게 다듬어 사용한다.
